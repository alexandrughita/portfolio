InstaSista

A free AI-powered Instagram posting assistant that generates branded carousel posts with high-quality images and captions. Each tenant gets a fully customizable experience — from a company following strict brand guidelines to a hobbyist sharing knowledge about their passion.

The Challenge / why this exists

The Problem

  • Creating quality Instagram content takes hours — writing captions, designing slides, finding images, picking hashtags
  • Social media tools charge $20-50/month per brand, making them impractical for small businesses or hobbyists
  • Generic AI generators produce bland, off-brand content that doesn't match a company's tone or visual identity
  • Hobbyists and niche creators struggle to maintain consistent posting without a design or copywriting background

The Solution

  • Type a topic, get a complete Instagram post in seconds — branded slides, ready-to-post caption, optimized hashtags
  • Each tenant gets their own branded portal with custom colors, fonts, logo, and tone of voice from a simple JSON config
  • AI follows brand guidelines automatically — audience, language, forbidden claims, required hashtags — like a trained social media manager
  • Pexels-powered background images matched to each slide's content, with dark/light mode and manual theme control

Tech Stack / what powers it

A pure Node.js application with zero framework dependencies. Gemini AI generates the content, Pexels provides images, and the entire multi-tenant system runs from simple JSON configuration files.

Key Features / what it does

Multi-Tenant Branding

Each client gets a unique visual identity from a single JSON file — custom accent color, font, logo, tone of voice, audience definition, and hashtag strategy. The system auto-generates a 5-theme color palette from one hex value using HSL shifts.

AI Content Generation

Gemini AI produces complete Instagram posts — carousel slides with headlines, stats, tips, and case studies, plus a full caption with hooks, CTAs, and optimized hashtags. The AI follows each brand's guidelines automatically.

Smart Background Images

The AI generates a search keyword per slide based on the content. Pexels API fetches matching high-quality portrait photos as slide backgrounds, with a cinematic dark overlay to keep text readable.

Per-Tenant Client Portal

Each tenant gets a branded URL (/c/clientId) with their own colors, font, and login. Clients can generate posts, connect Instagram, and export slides — without seeing other tenants.

Export-Ready Output

Save individual slides or the entire carousel as high-resolution JPG files (1080×1350px). Copy the caption and hashtags with one click. Ready to paste directly into Instagram.

Instagram OAuth Connect

Per-tenant Instagram account linking via Meta OAuth. Each client connects their own Instagram account for future automated posting and insights — tokens stored separately per tenant.

Flexible for Any Use Case

A bakery posting about daily specials following strict brand guidelines. An AI educator sharing knowledge with a casual tone. A startup announcing features. One system, infinite brand voices — all from JSON config.

Visual Customization

Dark/light background modes, 5 rotating color themes per brand, adjustable headline font size, theme selector per slide, and background pattern options (grid, dots, diagonal, noise, solid, image).

Security Built-In

Token-based tenant authentication with timing-safe comparison. Cookie sessions, in-memory rate limiting (10 gen/hour), XSS escaping on all AI output, CORS restriction, and input validation.

Architecture / how it works

A zero-dependency Node.js server that orchestrates AI generation, image search, and dynamic HTML rendering. Each tenant is a JSON file — no database required.
